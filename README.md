🦺 Edge-AI Smart Manufacturing PPE Detection System
Edge-AI based PPE detection system designed to improve worker safety at construction and manufacturing sites.
Uses YOLO-based object detection to identify workers and PPE compliance, including Hardhat, Safety Vest, Mask, and missing PPE.
Includes real-time camera monitoring, worker face recognition, safety-status detection, and violation alerts.
Provides an admin dashboard for viewing detection history, employee information, reports, and database records.
Supports Excel report generation and management of registered employees.
Built using Python, Flask, YOLO, OpenCV, MediaPipe, SQLite, HTML, CSS, and JavaScript.
